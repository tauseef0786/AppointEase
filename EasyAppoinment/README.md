# Doctor Appointment Booking System

This is a comprehensive Doctor Appointment Booking System built with React.js and Tailwind CSS. The application provides an elegant interface for patients to book appointments with doctors, view their appointments in a calendar, and manage their bookings.

## Features

- **Interactive Calendar Interface**: View appointments in daily, weekly, or monthly view
- **Appointment Management**: Create, edit, and delete appointments
- **Doctor Selection**: Choose from available doctors
- **Category Color Coding**: Visually distinguish different types of appointments
- **Dark Mode**: Toggle between light and dark interface themes
- **Responsive Design**: Works on all device sizes
- **Appointment Notifications**: Visual confirmation when appointments are booked or modified

## Technologies Used

- React.js
- Tailwind CSS
- React Context API (for state management)
- Lucide React (for icons)

## Running the Project Locally

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open your browser to the URL displayed in the terminal

## Project Structure

- `src/components/`: Contains all React components
- `src/context/`: Contains the AppointmentContext for state management
- `src/utils/`: Helper functions for date formatting and manipulation
